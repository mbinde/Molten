# Screenshot-Worthy Features

This document tracks features that should be prominently featured in app screenshots, documentation, and marketing materials.

## Kiln Schedules Feature

### 1. Kiln Schedule Creation & Management
- **What to show**: Creating a new kiln schedule with multiple segments (ramps and holds)
- **Why it matters**: Demonstrates the core functionality of managing complex firing schedules
- **Key elements**:
  - Schedule name and technique type
  - Visual representation of segments
  - Calculated total duration
  - Temperature units (F/C)

### 2. Segment Editor (Ramps & Holds)
- **What to show**: Adding/editing individual ramp and hold segments
- **Why it matters**: Shows the granular control users have over their firing process
- **Key elements**:
  - Ramp rate input (degrees per hour)
  - Target temperature
  - Hold time input (minutes)
  - Visual distinction between ramp and hold segments

### 3. Kiln Schedule Attached to Glass Item
- **What to show**: A glass item (e.g., frit, stringer, specific color) with recommended kiln schedules attached
- **Why it matters**: Demonstrates the integration between catalog and kiln functionality - users can see manufacturer-recommended or community-shared schedules for specific glass
- **Key elements**:
  - Glass item details page
  - "Recommended Schedules" section
  - Multiple schedule options for different techniques
  - Ability to quickly view or use a recommended schedule

### 4. Schedule List with Filtering by Technique
- **What to show**: Browse all schedules, filtered by technique (fusing, slumping, casting, etc.)
- **Why it matters**: Shows organization and searchability of complex schedules
- **Key elements**:
  - Technique filter chips/pills
  - Schedule cards with duration preview
  - Search functionality

### 5. Duplicate & Customize Schedules
- **What to show**: Duplicating an existing schedule and modifying it
- **Why it matters**: Demonstrates workflow efficiency - users can start with proven schedules
- **Key elements**:
  - Duplicate action
  - Modified name (e.g., "Full Fuse - Modified")
  - Quick editing of segments

### 6. Schedule Integration with Projects
- **What to show**: Attaching a kiln schedule to a project plan
- **Why it matters**: Shows end-to-end workflow from design to firing
- **Key elements**:
  - Project detail view
  - Schedule selection
  - Duration reflected in project timeline

## Screenshot Guidelines

When creating screenshots:
1. **Use realistic data**: Populate with actual glass manufacturers, real schedule names
2. **Show visual polish**: Ensure UI is clean, well-spaced, and professional
3. **Demonstrate value**: Each screenshot should answer "What can I do with this?"
4. **Platform-appropriate**: iPhone screenshots, iPad screenshots (if applicable)
5. **Accessibility**: Ensure text is readable, colors have sufficient contrast
