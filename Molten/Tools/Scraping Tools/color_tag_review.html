How to use this interface:

  • Checked boxes = approved tags. When you save, only checked tags will be saved for each product.
  • Green tags (NEW): We're suggesting these tags for the first time.
  • Red tags (REMOVED): You approved these before, but we no longer detect them. They're pre-checked so you can decide: keep checked to keep the tag, or uncheck to remove it.
  • Gray tags: Tags we're suggesting (haven't been approved before).
  • Use "Select All" / "Clear All" buttons to quickly select/deselect all suggestions for a product.
  • Click "Approve Tags" when you're happy with the selections for that product.
  • Use filters above to show only specific manufacturers or approval status.
