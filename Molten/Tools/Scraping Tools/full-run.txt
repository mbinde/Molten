⏺ Here's the full workflow to run everything from scratch:

  # 1. Run all scrapers (updates glass_database.json)
  cd "/Users/binde/projects/misc/Molten/Tools/Scraping Tools"
  python3 update_database.py --auto-commit

  # 2. Run tag analysis (analyzes all products, now with image analysis!)
  python3 color_tag_analyzer.py

  # 3. Review and approve tags in web interface
  ./review_color_tags.sh --review
  # (Opens browser at http://localhost:8080/color_tag_review.html)

  # 4. After approving tags, merge them back to database
  python3 merge_approved_tags.py

  # 5. Download any missing images
  python3 image_downloader.py

  # 6. Export final database for app
  python3 update_database.py --export glass_database_export.json

  # 7. Copy to app resources
  cp glass_database_export.json ../../Sources/Resources/glassitems.json

  Or if you want to do steps 1-2 in one shot:
  cd "/Users/binde/projects/misc/Molten/Tools/Scraping Tools"
  python3 update_database.py --auto-commit && python3 color_tag_analyzer.py

  Note: Step 2 (tag analysis) will now be slower since it's actually analyzing images with the
  vision API, but you'll get much better tag suggestions!
